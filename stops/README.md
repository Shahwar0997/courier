# stops/ — one folder per stop

Courier is built in **stops**: small steps, each ending in a pull request in this repo.
Each folder holds that stop's `WALKTHROUGH.md`: the expert's steps with the *why* for each one,
so you can follow it here in the editor, next to your code.

| Folder | Stop |
| --- | --- |
| `01/` | Your workshop: Git, GitHub, Codespaces, CI |
| `02/` | Plan a route: your first real program |
| `03/` | Make it move: your first firmware |
| `04/` | Sense and react: firmware that keeps looking |
| `05/` | Know where you are: measure, don't guess |
| `06/` | Talk to the robot: Wi-Fi, a command server, a tool for people |

Stop 0 (Meet Courier) happens on Curious Sims only; there's nothing to do in the repo yet.
Start with `01/`, even if you know Git: it sets up your own copy of this repo and your Codespace.
Later stops arrive as later folders.
